# Material de apoio da disciplina

Esta pasta reúne material histórico e didático separado do funcionamento
da aplicação:

- `grade-mlops-60h.md`: programa do curso.
- `mlflow_guia.md`: guia da aula, com exemplos da estrutura de referência
  `prj_churn`; não é o roteiro de instalação desta aplicação.
- `andamento_churn_completo.pptx`: apresentação de andamento.

Para executar e explicar a versão mantida, use o
[README principal](../../README.md), o [guia técnico](../guia-tecnico.md)
e o [manual de deploy](../deploy-ec2.md).
